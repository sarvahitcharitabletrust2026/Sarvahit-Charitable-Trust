GitHub and Vercel deployment steps

1. Create a new GitHub repository.
2. Upload all files from this outputs folder to that repository.
3. In Supabase, open SQL Editor and run supabase-setup.sql.
4. In index.html, update these two values:
   const SUPABASE_URL = "YOUR_SUPABASE_PROJECT_URL";
   const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
5. In Google Apps Script, create a project and paste in google-drive-upload.gs.
6. Deploy it as a Web app that executes as your account and is accessible to anyone. The gallery endpoint reads image files from the social activity folder configured in the script and returns a photo grid, including images inside its subfolders. All images in this folder will be visible to visitors through the public website.
7. Copy the Apps Script web app URL into both GOOGLE_DRIVE_UPLOAD_URL and GOOGLE_DRIVE_GALLERY_URL in index.html.
8. In Supabase SQL Editor, run supabase-pan-name-migration.sql once to add the PAN card number column to an existing database.
9. In Vercel, import the GitHub repository.
10. Use the default static site settings. The main file is index.html.

Important security note:
This static HTML version uses browser-side Supabase access. For a real owner-only volunteer list and delete action, create a backend/API route with secure authentication before making the site public.
